# U-Admin

## Установка

* установите [Node.js](https://nodejs.org/en/) (если требуется) и [Yarn](https://yarnpkg.com/en/docs/install): ```npm install --global yarn```
* скачайте необходимые зависимости: ```yarn```
* чтобы начать работу, введите команду: ```yarn dev``` (режим разработки)
* чтобы собрать проект, введите команду ```yarn build``` (режим сборки)


Результат записывается в `dist`.

## Готовая версия в `dist`

Папка `dist` содержит всё необходимое для интеграции сайта:

Готовые HTML, CSS, JavaScript, шрифты, изображения и библиотеки можно брать непосредственно из `dist`. Папку следует переносить целиком, чтобы сохранить относительные пути к ресурсам.

Править файлы в `dist` не рекомендуется: при следующем запуске `yarn build` папка очищается и создаётся заново. Изменения следует вносить в `src`, после чего повторно запускать сборку.


## Структура исходников

```text
src/
├── blocks/       # Pug-миксины и SCSS блоков
├── images/       # исходные изображения
├── js/           # JavaScript проекта
├── layouts/      # общий Pug-layout и базовые стили
├── pages/        # страницы проекта
├── public/       # статические шрифты и сторонние библиотеки
└── styles/       # общие стили, переменные и SCSS-миксины
```

## Backend

### Форма обратной связи

Разметка формы находится в `src/blocks/contact/contact.pug`, логика и правила валидации — в `src/js/index.js` в функции `initContactForm`.

Сейчас форма работает в демонстрационном режиме:

```pug
form.contact-form.js-contact-form.js-contact-form-validation.js-contact-form-demo(action='#')
```

Управляющие классы:

- `js-contact-form-validation` включает валидацию через JustValidate
- `js-contact-form-demo` отменяет реальную отправку и показывает экран успешной отправки

JustValidate подключён локально из `src/public/libs/just-validate`. При сборке библиотека автоматически попадает в `dist/libs`.

### Управление состоянием формы из отдельного JavaScript-файла

Форма поддерживает два пользовательских события:

- `contact-form:success` показывает сообщение об успешной отправке, очищает поля и переводит фокус на сообщение
- `contact-form:reset` скрывает сообщение и возвращает пользователя к форме

После успешного ответа сервера отдельный JavaScript-файл должен отправить событие на элементе формы:

```js
document.querySelector('form').dispatchEvent(new CustomEvent('contact-form:success'))
```

Если необходимо вернуться от сообщения об успехе к форме:

```js
document.querySelector('form').dispatchEvent(new CustomEvent('contact-form:reset'))
```
